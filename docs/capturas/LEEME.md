# Capturas

Renderizadas con [Paparazzi](https://github.com/cashapp/paparazzi) (motor de render de Android Studio en la JVM)
a partir de los **componentes de producción** de la app (`NowPlayingPanel`, `PresetKey`, `StationRow`,
`LinkSteps`, `SpeakerGrille`, tema `SoundTouchRadioTheme`) con **datos de ejemplo**: el altavoz «Salón»,
la IP y el firmware son ficticios. Perfil de pantalla: Pixel 6 (similar al Pixel 10).

No son capturas de un dispositivo real: el entorno de desarrollo no tenía emulador (sin KVM).
Paparazzi se usó solo para esta revisión y no forma parte del proyecto entregado.
